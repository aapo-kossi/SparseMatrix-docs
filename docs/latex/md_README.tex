\chapter{Sparse Matrix Library}
\hypertarget{md_README}{}\label{md_README}\index{Sparse Matrix Library@{Sparse Matrix Library}}
\label{md_README_autotoc_md0}%
\Hypertarget{md_README_autotoc_md0}%


This project implements a {\bfseries{sparse matrix library}} in C++, designed to handle both {\bfseries{dynamic (uncompressed)}} and {\bfseries{compressed}} storage formats. It supports matrix-\/vector multiplication, conversion between storage formats, norm calculations, and reading matrices from \href{https://math.nist.gov/MatrixMarket/}{\texttt{ Matrix Market}} files.

This project was developed as part of the Challenge 2 assignment for the 2024–2025 Advanced Programming for Scientific Computing Course at Politecnico di Milano.

\DoxyHorRuler{0}
 \hypertarget{md_README_autotoc_md2}{}\doxysection{\texorpdfstring{Functionality}{Functionality}}\label{md_README_autotoc_md2}

\begin{DoxyItemize}
\item {\bfseries{Templated Sparse Matrix Class}}\+: {\ttfamily Matrix\texorpdfstring{$<$}{<}T, Storage\+Order\texorpdfstring{$>$}{>}} supports both {\ttfamily row-\/major} and {\ttfamily column-\/major} layouts. It stores data in either {\bfseries{compressed}} or {\bfseries{dynamic (uncompressed)}}.
\item {\bfseries{Uncompressed (Dynamic) Format}}\+: Backed by a {\ttfamily std\+::map}, this format allows random insertions, deletions, and element modifications.
\item {\bfseries{Compressed Format}}\+: Uses {\bfseries{CSR (Compressed Sparse Row)}} for row-\/major matrices and {\bfseries{CSC (Compressed Sparse Column)}} for column-\/major ones. This format provides efficient iteration and matrix-\/vector multiplication.
\item {\bfseries{Automatic Format Detection}}\+: You can check if a matrix is compressed using {\ttfamily .is\+\_\+compressed()} and convert formats using {\ttfamily .compress()} or {\ttfamily .uncompress()}.
\item {\bfseries{Efficient Matrix-\/\+Vector Multiplication}}\+: Supports multiplication with both {\ttfamily std\+::vector\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} and {\ttfamily Matrix\texorpdfstring{$<$}{<}T, Storage\+Order\texorpdfstring{$>$}{>}} objects interpreted as column vectors. Optimized paths for both compressed and uncompressed formats.
\item {\bfseries{Matrix Norms}}\+: Implements {\ttfamily L1}, {\ttfamily L∞}, and Frobenius norms via {\ttfamily norm\texorpdfstring{$<$}{<}N\texorpdfstring{$>$}{>}()}, with optional parallelism. Norms are computed differently depending on compression format for best performance.
\item {\bfseries{Support for Scalar and Complex Types}}\+: Template-\/based design allows storage of real, complex, and integer values.
\item {\bfseries{Matrix\+Market Reader}}\+: Load {\ttfamily .mtx} files using {\ttfamily matrix\+\_\+market\+\_\+read(...)} — supports general real and complex matrices.
\item {\bfseries{Architecture-\/\+Specific Optimization}}\+: If AVX512 compatibility is detected on the build architecture, custom SIMD kernels are used to speed up norm computation in specific cases where automatic vectorisation is difficult.
\end{DoxyItemize}

\hypertarget{md_README_autotoc_md14}{}\doxysection{\texorpdfstring{Running the Test Suite}{Running the Test Suite}}\label{md_README_autotoc_md14}
To run the test program, you should provide {\bfseries{two required parameters}}\+:


\begin{DoxyEnumerate}
\item {\ttfamily -\/-\/test-\/matrix=\texorpdfstring{$<$}{<}path\texorpdfstring{$>$}{>}} Path to a {\ttfamily .mtx} file in \href{https://math.nist.gov/MatrixMarket/}{\texttt{ Matrix\+Market}} format. If this parameter is not specified, the test program tries to read a matrix stored in {\ttfamily data/lnsp\+\_\+131.\+mtx}.
\item {\ttfamily -\/-\/dtype=\texorpdfstring{$<$}{<}type\texorpdfstring{$>$}{>}} Data type of the matrix elements. Supported types are\+: {\ttfamily double}, {\ttfamily float}, {\ttfamily complex-\/double}, {\ttfamily complex-\/float}, {\ttfamily int32}, {\ttfamily int64}. By default, the matrix is created with {\ttfamily double} elements. The string {\ttfamily complex} can be used as a shorthand for {\ttfamily complex-\/double}.
\end{DoxyEnumerate}

⚠️ It is the user\textquotesingle{}s responsibility to supply the test matrix path and datatype correctly when launching the program. The data-\/type needs to be compatible with the data-\/type of the provided matrix.
